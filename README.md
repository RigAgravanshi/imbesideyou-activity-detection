# imbesideyou-activity-detection
#### Repository of the recruitment task for imbesideyou inc.

My current understanding of the task at hand is:
1. Reconstruct business-process executions from raw PC activity.
2. Validate boundary detection and process grouping using Dataset A.
3. Transfer the method (not Dataset A’s process labels) to the different workflows in Dataset B.
4. Analyse Dataset B for frequency, effort, variants, people involved, and automation potential.
5. Select the highest-ROI feasible process and build a working prototype.
6. Defend every decision through evidence, evaluation, trade-offs, risks, and a daily work log.
